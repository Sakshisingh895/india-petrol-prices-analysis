# India Petrol Prices Analysis & Tracker

## 📊 Project Overview

The **India Petrol Prices Tracker** is a data analytics project designed to track and analyze petrol prices across different Indian states over time.

The project captures petrol prices by state and date and calculates the change from the previous recorded price. It provides a structured view of petrol-price trends and enables comparison of prices across states.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Google Sheets
* Data Cleaning & Transformation
* Pivot Tables
* Excel Formulas
* Data Analysis
* Data Visualization
* Google Apps Script / Dashboard

## 📁 Dataset

The dataset contains **2,280+ petrol-price records** with the following fields:

| Column      | Description                     |
| ----------- | ------------------------------- |
| Date        | Date of the petrol-price record |
| State       | Indian state                    |
| Petrol_Rate | Current petrol price            |
| Prev_Petrol | Previous petrol price           |
| Change_Rate | Change in petrol price          |
| Source      | Data source URL                 |

## 🔍 Analysis Performed

* Tracked petrol prices across Indian states.
* Compared petrol prices between states.
* Monitored changes in petrol prices over time.
* Calculated price changes using current and previous petrol rates.
* Identified states with relatively higher and lower petrol prices.
* Created a dashboard for easier monitoring and comparison.
